# WMS 操作介面規則

以下規則適用所有角色、頁面與後續功能。操作畫面是讓人員完成工作的工具；交付文件才放設計理由與完整教學。

- 進入頁面時，讓人員立即看懂目前任務、下一步動作與完成狀態。以標題、欄位、按鈕與狀態表達，不在每個區塊預設加入介紹或教學段落。
- 依登入角色及任務階段顯示內容。主要動作清楚可見；低頻設定、歷史與進階資訊按需展開。不要為填空白加入統計卡、裝飾或提示框。
- 同一任務盡量在同一情境完成。自動帶入已有資料並自動執行可確定的規則；需要判斷時只呈現必要選項。不得藉簡化移除權限、稽核、驗證、防重或高風險確認。
- 使用現場人員熟悉且表達結果的名稱，例如「列印預揀總表」「核對銷貨結果」。同一功能的名稱、位置與操作方式保持一致。
- 用清楚層級、可讀字級及對比呈現。異常在對應操作旁簡短顯示；成功以簡短狀態回饋，不依賴每次都要關閉的視窗。
- 交付前按行政、主管、預揀、揀貨、裝箱等實際角色走完常見任務，記錄多餘的閱讀、輸入、點擊與跳頁。若必須靠大段說明才能懂，先調整流程與命名。

格式限制、資料錯誤及刪除／付款等風險警告仍須就近明確顯示。
