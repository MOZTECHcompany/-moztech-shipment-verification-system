# 三平台原始訂單轉檔：2026-09-16

## 本次變更

- SHOPLINE 原生 XLS 報表使用「商品結帳價」，支援逐列商品折扣、全單折扣、購物金及點數分攤。來源訂單小計與各折抵金額保留於快照；輸出逐列淨額。每種折抵分攤合計必須與原訂單相符，不能倒推金額或把重複商品合併後丟失成交資訊。
- 原生報表要求退款、幣別、稅費、附加費與折抵欄位。已發貨、部分發貨、已取消、退款與未知狀態不納入。COD 保留未付款狀態。
- 缺少或矛盾金額、未驗證組合主子商品、非零另列稅費／附加費、無法用兩位小數單價表達的淨額仍會阻擋，不能宣稱所有情境皆可自動放行。
- ECOUNT 下載使用 2026-09-15 實際線上上傳欄序：A:L 原標準欄位，M:W 為品項名稱至產生生產入庫，X:AA 為商城訂單編號、平台、店鋪、來源明細號。P 為數量，R 為含稅單價。
- 快照與 API 的既有 canonical 欄序不變；下載時按欄名重排。既有批次可重新下載，不必重建或重複上傳 ERP。ECOUNT 若另改格式，必須重新核對上傳表頭。
- SHOPLINE 訂單標籤、合作夥伴及推薦代碼保留在來源快照；不把標籤當作保留庫存，也不臆測商品分類就是團購主。
