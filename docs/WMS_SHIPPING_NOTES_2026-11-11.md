# 理貨單出貨備註

匯入理貨單時，在「品項編碼」填 `WMS-NOTE`，「品項名稱」填廠商要求的文字，例如「採購單號：PO-000123」。數量填 0 或留空，不附商品條碼或 SN。可以有多列備註。

備註會在揀貨、裝箱及專注模式顯示，並在出貨明細 XLSX 保留原文、`WMS-NOTE` 及數量 0。備註不算商品件數，不會進入掃碼流程。正常商品仍須通過原本的數量與 SN 驗證；備註列填非零也會退件。功能適用於新匯入的理貨單，現有訂單不會被重複建立。

發布需先執行加欄位的 migration 044。備註與訂單在同一交易保存，讀取沿用原本訂單權限。回復應用程式版本時保留已匯入的備註欄位，不回灌資料庫。
