# 已保存訂單的收件資料修正

## 操作

再次上傳已保存的商城訂單時，「查看原訂單」開啟原批次並定位該訂單。Shopify 訂單可從「更新收件資料」讀取商城最新收件資料，核對前後內容後「保存收件資料」。

目前只處理原訂單的收件資料。這個操作不建立新銷貨檔、不重複扣庫、不重新建立工作單，也不恢復作廢工作單。

## 邊界

- 保留原始 CSV、來源訂單／明細、商品、數量、金額、稅、ECOUNT 檔案與批次唯一性。
- 保存前重新讀取 Shopify，確認同一店鋪與訂單，商品、數量、金額及狀態符合原始證據；缺少收件人、電話或地址時停止。
- 已封存、開始預揀、已有掃碼／認領／作廢紀錄、物流單或開放中的訂單異動，不直接修改；由主管處理原單。
- 保存只修改原訂單的 shipping，記錄登入人員、前後內容與操作識別；狀態變動、重複請求及提交結果未知時，不建立第二次更新。
- WMS 未收到 ECOUNT 回匯，不代表 ECOUNT 尚未銷貨。重新銷貨、取消銷貨與重建倉庫作業，需先確認原 ERP 銷貨狀態。

## 驗證

本次以 DEV 中 #154319／批次 #19 做唯讀 Shopify 與原單核對。實際保存收件資料及現場出貨由使用者實測；不在驗證時更新真實收件資料、銷庫或建立物流單。
