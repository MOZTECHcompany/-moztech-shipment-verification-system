# SN 批次整批箱號倉儲明細匯出

「SN 與標籤 → 配號與匯出 → 箱號倉儲明細 XLSX」改為預設選取整個批次的箱序，可一次下載全部箱號。若曾調整範圍，可按「選取全部箱號」恢復；也保留指定箱序匯出。

後端與 Excel 產生器移除 100 箱上限。箱序改以實際批次箱數驗證，不再套用單件 SN 匯出每次 10,000 個的限制。活躍批次、操作權限、箱內數量與 SN 一致性，以及輸出稽核仍照常檢查。

XLSX 保留「箱號明細」及「倉儲明細」兩張表，欄位與順序相同。有 SN 批次帶出每箱完整 SN；無 SN 批次保留數量、國際條碼或內部掃描碼。匯出不調整庫存、箱內容或批次入庫狀態。

## 驗證

- 真實 API 配號、追加及 XLSX 讀回：有 SN 102 箱／10,101 SN；無 SN 10,001 箱。逐箱核對兩張表的箱號、數量、SN、商品、掃描碼及來源批次。
- 驗證末段指定範圍、無效箱序、無權限、已退回批次及原有單件輸出上限。
- 本機瀏覽器配合一次性 PGlite 資料庫：有 SN／無 SN 各 102 箱，預設全部、修改範圍後恢復全選、實際下載 XLSX 並核對各 1,020 件均通過。
- 既有後端 308 項、前端 266 項測試，以及前端 production build 通過。其他箱號／理貨整合回歸通過 119 項；真實 PostgreSQL 專用案例因未啟用本機 PostgreSQL 而跳過。
