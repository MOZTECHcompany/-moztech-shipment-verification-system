# 操作日誌智慧搜尋

在「設定 → 操作日誌」輸入訂單編號、人員、客戶、操作名稱，或掃描記錄中的條碼／序號。多個詞以空白分開，每個詞都要符合該筆記錄的某個欄位。例如 `王小姐 裝箱`。訂單日期片段（如 `2026/10/19`）用來找單號；「操作日期」篩選才限制日誌發生時間。

- 常用日期採台灣時間；「進階篩選」可查確切操作、工序、人員 ID 和日期範圍。已套用條件可逐一移除。
- 結果以最新操作在前。新事件提示更新，由伺服器重新套用條件；列表不插入未確認符合的事件。
- 可切換分頁、開啟單筆詳情、查看目前條件統計，以及匯出本頁 CSV。詳情保留原始記錄；匯出保留歷史操作者身分與當下工序，並防止試算表將文字當公式。

兩個操作日誌 API 維持管理員權限與既有參數。清單以 `created_at, id` 分頁，`total` 仍是本頁筆數，`nextCursor` 為下一頁游標；統計忽略游標與頁大小。條碼／序號限於掃描相關記錄中合法 JSON 的既有欄位，歷史資料缺少欄位時不補造。此更新不需要資料庫 migration。

驗證使用合成操作日誌，涵蓋日期邊界、不同格式的單號、分頁、權限及統計。正式環境目前版本仍以 Cloud Run revision、traffic 和 image digest 的讀回結果為準。
