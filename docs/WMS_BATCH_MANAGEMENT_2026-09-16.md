# 商城批次管理

## 行為

- 商城轉檔仍保存原始訂單、金額、商品對照與來源明細；原有 ECOUNT 27 欄輸出及角色限制保留。
- 列表按銷貨日期分組，支援日期區間、平台、店鋪、追蹤單號／批次 ID 和封存狀態；後端每頁 20 批，不再只提供最近 100 批。
- `?batch=<id>#batch-detail` 可直接開啟保存快照，查看每筆商城訂單及商品；回匯後連到既有理貨批次列印頁。
- 銷貨檔、WMS 預揀總表與訂單明細均由保存的快照下載，不依賴本次上傳草稿。預揀 Excel 不是 ERP 原始理貨回匯檔；WT 及掃碼紙本要在 ERP 理貨回匯後由既有批次列印功能產生。
- 封存只改可見狀態，保存快照、來源訂單去重及理貨回匯對應皆保留。可取消封存。
- 永久刪除只允許沒有理貨關聯的批次，先顯示二次確認及不可復原提示。後端驗證 confirmed 與批次追蹤號，並在與匯入相同的來源鎖內重新檢查關聯。刪除批次及來源對應後，保留操作人、時間、批次號、動作等稽核中繼資料。刪除不撤銷 ERP 銷貨／庫存。
- 拋單員、管理員與最高管理員可管理，揀貨員／裝箱員無權限。
- 大面積拖曳框在拖入時顯示提示；檔案選取與拖曳共用解析和限制。
