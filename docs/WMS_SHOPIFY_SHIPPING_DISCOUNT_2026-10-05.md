# Shopify 商品與運費折扣核對

## 原因

`墨超 七 1005-2.csv` 的 `#154328`：商品原價 690 × 2 = 1,380 元，商品成交額 1,369 元；運費原價 80 元、折後 0 元；全部折扣 91 元。Shopify 即時 API 與原始 CSV 相符。舊核對只拿商品折扣 11 元比全部折扣 91 元，錯誤阻擋免運訂單。

## 修改

- 讀取 Shopify 2026-07 的完整運費列、移除狀態、原價及目前成交額；有效運費合計必須等於訂單目前運費。
- 商品折扣加上運費折扣必須等於目前全部折扣。金額仍以整數分核對，不放寬差額。
- 傳給既有轉檔器的運費使用折後運費，折扣使用商品折扣，避免運費折扣再次扣到商品。完整原運費、折扣及運費列另存來源證據，納入 v2 指紋及分頁一致性檢查。
- 全部歸零且已取消的訂單，原運費減少記為取消沖除，不計成折扣、不恢復舊 CSV 商品。例如 `#154376` 原運費 80 元、目前交易全部為零。
- 缺少正式貨號的自訂商品保持阻擋，提示在 Shopify 改用正式商品。例如 `#154333` 目前商品只有品名文字寫貨號，實際 SKU 與 variant 均空白；不得從品名或已移除 CSV 商品推測出貨品號。

## 驗證範圍

- 真實訂單及 CSV 全程唯讀；不修改 Shopify 訂單，不保存測試批次，不執行 ECOUNT 銷庫。
- 回歸涵蓋商品及免運混合折扣、單獨運費折扣、多運費列、移除列、訂單修改、取消、分角精度、整元分攤、不完整或重複明細及跨頁資料變更。
- `#154328` API → 解析 → 彙總 ECOUNT 銷貨格式：數量 2、含稅 1,369 元、加權含稅單價 684.5 元、稅前 1,304 元、營業稅 65 元。免運不產生付費運費列。
- 本次只更新 DEV；實際發布、唯讀查核及測試證據保存在工作區外 `artifacts/wms-shipping-discount-20261005`。這份完整批次仍需修正 `#154333` 的 Shopify 自訂商品後重新查核。

官方欄位：[ShippingLine](https://shopify.dev/docs/api/admin-graphql/2026-07/objects/ShippingLine)、[Order](https://shopify.dev/docs/api/admin-graphql/2026-07/objects/Order)。
